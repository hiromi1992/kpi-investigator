# KPI Investigator v0.7

**PythonベースのKPI分析と根拠付き説明を、合成ECデータで試せるポートフォリオアプリです。**

この公開準備版は **AI・Redisへの実接続なし** のオフライン分析モードです。実API呼出、外部CSV送信、ログイン、予測、自由入力型AI質問は行いません。公開URLはまだありません。実公開環境での動作は未検証です。

## できること

- 付属の合成CSVから「総合レポートを生成」を1回押し、7つのPython分析を実行
- 売上・注文・チャネル・商品・前月差・売上差額の検算・日次差を確認
- 確認済み事実と解釈・不明点を分離。説明文を事前生成済みと明示
- 実行済み8ステップを再生し、実際のPython関数コードとSHA照合を表示
- 2種類のCSVを読み込み、日付・注文重複・欠測を検証して不正な前月比較を抑制

## ローカルで動かす

Python 3.12以降を推奨します。任意の隔離仮想環境内で以下を実行してください。

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

起動後、ローカル画面で合成デモを選び、総合レポートを生成してください。テストは `python -m pytest -q tests/` で実行できます。

## データ・安全性

- `fixtures/` のCSVと固定説明は合成データです。実顧客データは収録していません。
- 利用者のCSVはこの版ではAIサービスへ送信されません。個人情報や機密情報はアップロードしないでください。
- CSVの明細そのものは長期保存する目的で実装されていません。公開環境の秘密非露出や実ホスト運用は別途検証が必要です。
- AI・Redis・費用上限を伴うライブモードは **未実装・未設定・未公開** であり、この版の動作保証外です。
- 固定説明はライブAI応答ではありません。画面には非ライブと明記します。

## 実装の見どころ

`kpi_investigator/data.py` はデータ品質、`analysis.py` は7分析、`interpretation.py` は説明の根拠検証、`trace.py` はソース照合を担当します。`ai.py` と `quota.py` は将来の実接続に向けた**モック契約**で、通信はしません。

現行のレビュー結果は **F01・F02の独立Focused I3が限定PASS**。ただし、製品全体の公開受入・本番API/Redis・費用管理・実公開UXの合格を意味しません。
